## 🚀 About The Project

**ExpoLearn** is a beginner-friendly React Native application created
to explore the fundamentals of mobile application development using Expo.

The project started as a simple login screen and was progressively
upgraded with a cleaner interface, interactive components, validation,
navigation and a dedicated profile experience.

The project demonstrates how a basic Expo application can be transformed
into a more polished and presentation-ready application.

---

## ✨ Features

### 🔐 Login Experience

- Modern login interface
- Name input
- Password input
- Password show/hide functionality
- Empty-field validation
- Login success alert
- Interactive button feedback

### 👤 Profile Screen

- User avatar
- User name
- Learning role
- Application information
- Learning level
- Project status
- Back-to-home navigation

### 🎨 UI Improvements

- Modern card-based layout
- Rounded input fields
- Rounded buttons
- Shadows and elevation
- Better spacing
- Clean typography
- Responsive web layout
- Interactive press effects

### 🧭 Navigation

- Expo Router
- Home screen
- Profile screen
- Navigation links
- Back navigation
